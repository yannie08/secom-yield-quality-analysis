# Semiconductor Manufacturing Yield & Quality Analysis

A semiconductor manufacturing quality analysis project based on the UCI SECOM dataset.

## Project Objective

This project aims to:

- Analyze Pass and Fail manufacturing results
- Handle missing values and class imbalance
- Build basic classification models
- Identify candidate abnormal process parameters
- Develop a quality monitoring dashboard
- Provide an 8D/RCA-style quality analysis report

## Tools

- Python
- Jupyter Notebook
- SQL
- Power BI
